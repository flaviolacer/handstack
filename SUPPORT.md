# Support

HandStack is an open-source project under active development. Before asking for help, check the
[README](./README.md), [documentation](./docs/content/en/getting-started/overview.mdx), and
[troubleshooting guide](./docs/troubleshooting.md).

## Where to ask

- **Bug:** open an issue with the bug-report template and include the smallest reproducible example.
- **Feature idea:** open an issue with the feature-request template and describe the problem before
  proposing an implementation.
- **Usage question:** use GitHub Discussions when enabled for the repository.
- **Security vulnerability:** do not open a public issue; follow [SECURITY.md](./SECURITY.md).

## Include in a useful report

- HandStack version or commit;
- Node.js and npm versions;
- operating system and deployment profile;
- relevant package or service;
- exact commands and sanitized logs;
- expected and actual behavior;
- a minimal reproduction when possible.

Never include passwords, API keys, access tokens, private customer data, or production secrets.

## Support boundaries

The maintainers can help with reproducible project behavior and documentation. Production operations,
managed-provider availability, infrastructure costs, and organization-specific security decisions
remain the responsibility of the deploying team.
