# HandStack

HandStack is an open-source AI workspace, agent runtime, gateway, and capability platform.

The central abstraction is a **Capability**. Web, REST, MCP, and Agent channels must execute capabilities through the same governed execution pipeline.

This repository is under active construction according to the normative project specification. See [STATUS.md](./STATUS.md) for verified progress and pending work.

## Prerequisites

- Node.js 22 or 24 LTS
- npm 11 (ou yarn, quando `yarn.lock` existir)

## Commands

```bash
npm install
npm run lint
npm run typecheck
npm run test
npm run build
```
