# Configure Redis Streams and durable queues

Inject a `RedisStreamsTransport` into `RedisStreamsEventBus` and a
`DurableJobTransport` into `DistributedJobQueue`. The adapters may use Redis
Streams and BullMQ clients, while the contracts keep local tests SDK-free.

## Prerequisites

- Redis HA/Sentinel or managed Redis with persistence and network policy.

## Steps

1. Configure a highly available Redis endpoint and consumer group per worker class.
2. Append events before acknowledging the HTTP request; handlers ACK only after success.
3. Route poison events and terminal jobs to a retained dead-letter stream/queue.
4. Set bounded backlog and honor `BackpressureError.retryAfterSeconds`.

## Verify

Exercise consumer redelivery, handler failure/DLQ, bounded admission and graceful worker shutdown.

## Troubleshooting

- A missing ACK is redelivered by the consumer group; inspect handler errors before increasing retries.
