# Validate provider metadata before registration

## Prerequisites

- A plugin host with a provider registration callback.
- A descriptor with a lowercase stable provider ID, display name, capability and non-empty configuration schema.

## Steps

1. Register the provider from plugin setup.
2. Let the host call `validateProviderRegistration` before forwarding the descriptor.
3. Resolve the descriptor into the appropriate domain registry only after validation and policy checks.

## Expected results

Invalid IDs, empty names/capabilities or empty schemas fail before the host callback and create no registration side effect.

## Verify

Run the Plugin SDK contract tests and confirm invalid provider metadata fails closed.

## Troubleshooting

- `Provider id is invalid` means the provider ID is not a stable lowercase identifier.
- `Provider configuration schema is required` means the host cannot safely configure the provider.
