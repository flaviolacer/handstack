# Resolver extensões UI de plugins autorizadas

## Prerequisites

- Um `PluginUiRegistry` com descritores de extensão validados.
- A lista de permissões efetivas do principal obtida pelo limite normal de autorização.

## Steps

1. Passe a lista efetiva de permissões a `listAuthorized`.
2. Opcionalmente passe a capability exigida pela superfície atual do host.
3. Renderize ou invoque somente os descritores retornados e valide autorização novamente no limite da ação.

## Expected results

Extensões sem a permissão declarada não são retornadas. O filtro de capability reduz o resultado sem conceder novas permissões.

## Verify

Execute os testes do Plugin SDK com administrador e principal sem a permissão; somente a extensão autorizada deve aparecer.

## Troubleshooting

- Resultado vazio indica que nenhuma extensão atende à permissão e capability opcional.
- Este resolver não concede autorização; o limite do servidor/ação ainda deve aplicar a política.
