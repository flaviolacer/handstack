# Observabilidade e alertas

O HandStack fornece um contrato versionado de dashboard e alertas de SLO cobrindo latência,
streams, pressão do runtime, autoscaling, filas, workers, Redis, banco, providers, budgets e
storage. Importe `deploy/observability/handstack-slo-dashboard.json` no sistema aprovado e adapte
`deploy/observability/handstack-alert-rules.json` ao formato Prometheus da plataforma.

Execute `npm run observability:validate` na validação de release. Métricas não podem conter prompts,
payloads, secrets, IDs de tenant, IDs de usuário ou nomes de modelos.

## Prerequisites

Você precisa de acesso de deployment e de um sistema de métricas e alertas compatível com
Prometheus.

## Steps

1. Exponha o endpoint `/metrics` do HandStack ao coletor aprovado.
2. Importe o JSON do dashboard de SLO e adapte as regras de alerta ao formato da plataforma.
3. Configure os destinos dos alertas e vincule cada alerta ao runbook fornecido.

## Verify

Execute `npm run observability:validate` e confirme que o dashboard carrega todos os painéis e que
cada alerta referencia uma métrica catalogada.

## Troubleshooting

Se uma métrica ou painel estiver ausente, compare a revisão implantada com o catálogo versionado e
execute novamente o gate de validação. Não adicione dados sensíveis da requisição como label para
corrigir problemas de cardinalidade ou filtragem.
